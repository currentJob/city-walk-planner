# 홍콩·마카오 트렌드 코스 카테고리

사용자 요청: 인스타·요즘 트렌드에 맞춘 홍콩·마카오 일정, 가게 단위 평점·리뷰 요약, 영업시간, 꿀팁을 별도 카테고리로 작성한다.

## 구현

- 메뉴에 `#trend` "홍콩·마카오 트렌드"를 추가했다. `#trend-<가게 id>`로 해당 가게 카드에 바로 연결된다.
- 자료: `src/harbor_lantern/web/data/hk-macau-trend.json` (2026-10-05~08, 4일, 방문지 30곳, 가게 15곳, 명소 15곳, 팁 8개).
- 화면: `src/harbor_lantern/web/js/render/trend.js` (순수 함수 `trendHtml`, `positiveShare`). 기존 `.day`·`.stop`·`.place-card` 스타일을 재사용했고 새 CSS는 없다.
- API·DB·의존성은 바뀌지 않았다. 정적 Pages 배포만으로 반영된다.

## 조사 근거 · 2026-09-28

- 가게 평점: OpenRice 가게 페이지의 좋아요·보통·별로 수와 리뷰 수. 긍정 비율 = 좋아요 ÷ 세 값의 합. Australia Dairy는 "보통" 수를 확인하지 못해 비율을 표시하지 않는다.
- 리뷰 요약: OpenRice 리뷰의 반복 경향을 한국어로 다시 쓴 것이며 원문 인용이 아니다. 요약 모델을 거친 추출이므로 원문 확인을 권한다.
- 영업시간: 가게는 OpenRice, 명소는 공식 페이지(Tai Kwun, M+, TWGHs 만모 사원, Cotai Water Jet, Wynn, Londoner, Tourism Commission)를 따랐다. 피크 트램 요금과 시간은 공식 페이지 접근이 차단되어 검색 결과로 교차 확인했다.
- 요일 휴무를 반영했다: Australia Dairy 목, Mido·Margaret's 수, M+ 월, 싱흥원·란퐁유엔·카우키 일. 마가렛 카페는 수요일인 마카오 날에 쉬므로 대안으로만 두었다.

## 미확인·주의

- TurboJET 공식 사이트(www2.turbojet.com.hk)는 봇 확인 화면만 반환해서 우회하지 않았다. 외항 터미널 노선이 2026-06-15부터 타이파로 옮겨졌다는 보조 자료가 있지만 원문은 확인하지 못했다. 그래서 공식 시간표를 확인한 Cotai Water Jet 타이파 노선으로 코스를 짰다.
- 위 사항 때문에 기존 `data/macau-day-trip.json`(외항 터미널 기준, 2026-09-18 조사)의 최신성을 다시 확인해야 한다. 이번 범위에서는 수정하지 않았다.
- 심포니 오브 라이트는 2026년 하반기에 종료될 예정이고 종료일은 발표되지 않았다.

## 추가: 방문 기간 지정 일정 짜기 · 2026-09-28

- 요청: 트렌드 화면에서 방문 일자를 지정하면 그 기간에 맞는 일정을 짜 준다.

## 추가: 숙소 기준 일정 · 2026-09-28

- 요청: 방문 기간과 함께 숙소 여러 곳(숙박일, 입실·퇴실 시각)을 입력하면 숙소를 기준으로 일정을 계획한다.
- 입력: 숙소마다 이름, 지역, 입실일·시각, 퇴실일·시각을 받는다. 지역은 5곳 중에서 고른다(센트럴·셩완, 완차이·코즈웨이베이, 침사추이·조던·몽콕, 마카오 반도, 타이파·코타이). 지오코딩과 외부 호출은 없다.
- 자료: `areas`, `travel_minutes`(지역 간 추정 이동 분, 홍콩↔마카오 90분), 코스마다 `start_area`·`end_area`.
- 배치:
  - 날마다 아침 숙소(전날 밤 숙소, 첫날은 입실 숙소)와 밤 숙소를 정한다. 마지막 날은 밤 숙소가 없다.
  - 비용에 "아침 숙소 → 코스 시작 지역"과 "코스 끝 지역 → 밤 숙소"의 추정 이동 시간 ÷ 15를 더한다.
  - 숙소를 입력하면 모든 날짜 조합을 탐색한다. 숙소가 없으면 기존 배치를 그대로 쓴다.
- 일정 표시:
  - 퇴실은 그날 맨 앞에 "~HH:MM"으로, 입실은 해당 시각에 넣는다.
  - 입실이 코스 중간에 걸리면 안내한다.
  - 마카오에서 자는 날은 돌아오는 페리를, 마카오에서 출발하는 날은 가는 페리를 뺀다.
  - 마카오 숙소에서 홍콩 코스로 가거나 홍콩 코스 뒤 마카오 숙소로 돌아가는 날에는 페리 안내를 붙인다.
- 입력 검증: 지역 누락, 날짜·시각 누락, 퇴실일이 입실일보다 빠르거나 같음, 방문 기간 밖, 숙박일 겹침.
- 한계: 지역 단위 추정 이동 시간이며 실제 경로가 아니다. 숙소 입력은 저장하지 않는다(새로고침하면 사라짐).
- 검증:
  - PASS `PYTHONUTF8=1 uv run pytest -q`: 925 passed. `test_trend_schedule_follows_stays`는 까우룽 숙소만 있으면 기본 코스 유지, 10/7 마카오 숙박 시 그날 마카오 코스와 가는 페리만 남음, 퇴실이 맨 앞, 입실 표시, 마지막 날 밤 숙소 없음, 7일 중 마카오 숙박일로 마카오 코스 이동, 잘못된 입력 6종, 숙소 이름 이스케이프를 검사한다.
  - PASS ruff, `.github/quality/gate.py` 4/4.
  - PASS 브라우저(1280px·390px): 숙소 추가 시 앞 숙소 퇴실일로 자동 채움과 포커스 이동, 삭제, 두 숙소 일정 반영, 겹침 오류 표시, 가로 넘침·콘솔 오류 없음. 창이 숨겨져 있어 클릭은 스크립트로 대신했다.
