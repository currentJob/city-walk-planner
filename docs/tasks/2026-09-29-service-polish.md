# 알림 자동 닫힘 · 내 여행 삭제 · 연결 설정 제거

사용자 요청:
- 상단 경고·알림은 일정 시간이 지나면 사라지게 한다.
- "내 여행"의 마카오 일정 추가 기능을 삭제한다.
- "내 여행"에 저장된 일정을 삭제할 수 있게 한다.
- 하단 연결 설정은 환경 변수 등 별도로 관리하고, 화면에는 사용자에게 필요한 정보만 둔다.
- 그 밖에 운영 서비스에 알맞은 기능을 적용·개선한다.

## 변경

- **상단 알림**(`explore.js` `notice()`): 헤더 아래에 떠 있다가 저절로 사라진다.
  - 일반 알림 4.5초, 오류 7초, 되돌리기 알림 8초.
  - 마우스를 올려 두거나 알림 안에 포커스가 있으면 기다린다.
  - 닫기(×) 버튼이 있다. 오류는 `role=alert` 로 알린다.
  - 동행 페이지는 원래 3.2초 뒤 사라지는 알림을 쓰고 있어 그대로 두었다.
- **마카오 추가 기능 삭제**
  - "홍콩 여행에, 마카오 하루" 제안 영역, `renderMacauOffer`·`withMacauDay`·`restoreMacauDay`·`canAddMacau`, `data/macau-day-trip.json` 을 지웠다.
  - 이미 마카오 하루를 넣어 저장한 여행은 계속 읽히도록 `excursionHtml` 만 남겼다.
- **내 여행 카드와 삭제**
  - 카드에 목적지, 기간, 일수·장소 수, 마지막 저장 시각(`saved_at`)을 보인다.
  - "여행 열기"와 "삭제" 버튼이 있다.
  - 삭제는 확인 창 없이 바로 하고, 알림의 "되돌리기"로 원래 자리에 되살린다.
- **연결 설정 제거**
  - 메인 화면 하단 "연결 설정"과 동행 페이지의 "백엔드 주소" 칸을 지웠다.
  - 서버 주소는 빌드 설정(`CWP_API_BASE` → `config.js`)이나 동일 출처로만 정한다.
  - `?api=` 링크와 브라우저에 저장된 주소(`hl_api_base`)는 더 이상 쓰지 않고, 남아 있으면 지운다. 링크 하나로 요청(참여 토큰 포함)이 다른 서버로 갈 수 있던 문제도 함께 없어진다.
  - 이 링크 방식을 쓰던 `tools/notify_tunnel.py`(Telegram 터널 링크)와 그 테스트를 지웠다. `start-tunnel.ps1` 의 알림 호출도 지웠다. README 의 이전 방식(PC 백엔드) 절에는 주소를 `CWP_API_BASE` 로 넣는다고 고쳐 적었다.
- **운영용 추가**
  - 일정 파일 불러오기: "일정 내려받기"로 받은 .json 을 다시 내 여행에 넣는다. 모양이 맞지 않거나 2MB 를 넘는 파일은 거절한다. 같은 파일을 두 번 넣으면 따로 저장된다.
  - 내려받는 파일 이름에 목적지를 넣는다(`travel-홍콩-2026-10-05.json`).
  - 오프라인이 되거나 다시 연결되면 알린다.
  - 링크 공유용 Open Graph 메타 태그를 넣었다.
  - 자바스크립트가 꺼져 있으면 안내 문구(noscript)를 보인다.
