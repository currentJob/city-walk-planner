# 모바일 전용 레이아웃

사용자 요청: 모바일 화면이 불편하므로 모바일은 별도로 구현해 레이아웃과 디자인을 다시 잡는다.

## 변경 전 측정 · 375×812

- 상단 헤더 100px 고정(메뉴 5개, 글씨 12px). 모바일에서 "동행과 함께" 링크가 숨겨져 동행 화면으로 갈 방법이 없었다.
- 트렌드 화면 25화면 길이, 지도는 스크롤 1,073px 아래에서 시작.
- 도시 상세 21화면, 높이 16~21px 링크 다수(작은 터치 영역 144개). 일정 화면 순서 버튼 폭 26px, 라벨·배지·출처 10~11px. 사진 출처 9px.

## 구현

- `css/mobile.css`를 새로 만들어 `media="(max-width: 760px)"`로 `platform.css` 뒤에 불러온다(index.html, hongkong.html). `platform.css`에 흩어져 있던 760px 규칙 6곳을 이 파일로 옮겼다. PC 화면은 바뀌지 않는다.
- 상단 바 56px(브랜드 + "동행" 버튼), 메뉴는 하단 고정 탭바 62px로 옮겼다. 아이콘(인라인 SVG)과 짧은 이름을 쓰고, 안전 영역(`viewport-fit=cover`)을 반영했다. 링크마다 `aria-label`에 전체 이름을 넣었다.
- 글씨는 최소 12px로 맞췄다. 버튼·입력·접기 제목·탭은 44px 이상, 문장 속 링크는 위아래 여백으로 누르는 영역을 28px 이상으로 넓혔다(WCAG 2.2 AA 기준 24px).
- 일정 화면의 날짜 탭은 스크롤해도 상단 바 아래에 고정된다.
- 장소 추가 창은 전체 화면으로 연다.
- 트렌드 화면은 모바일에서 일정 / 지도 / 가게 / 명소 / 팁 탭으로 한 영역씩 보여 준다. 탭을 바꾸면 맨 위로 이동한다. 지도 탭은 화면을 채우고, 핀을 누르면 일정 탭으로 넘어가 해당 방문지를 강조한다. `#trend-<가게>` 링크는 가게 탭을 연다. 가게 카드의 리뷰 요약·결제·가는 길은 모바일에서 접혀 있고 PC에서는 펼쳐진 채 접기 제목이 숨겨진다.
