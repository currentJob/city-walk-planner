# 지도 ↔ 목록 연결

사용자 요청: 지도가 있는 화면에서 두 방향 이동을 만든다.
- 항목을 누르면 지도로 이동해 그 좌표에 초점을 맞추고 간단한 정보 팝업을 연다.
- 지도 핀을 누르면 간단한 설명 팝업이 뜨고, 팝업을 누르면 그 항목으로 스크롤한다.

## 변경

- `js/map.js`
  - `popupHtml()`: 팝업 본문. 제목, 설명 줄, "목록에서 보기" 버튼으로 이루어진다.
  - `shortText()`: 긴 설명을 70자로 자른다.
  - `scrollToItem()`: 항목으로 스크롤하고 잠깐 강조한다(`.map-hit`).
  - `TripMap._onPopupClick()`: 팝업을 누르면 목록으로 간다. 링크는 제외한다. Leaflet 이 팝업을 열 때마다 본문을 다시 그리므로 그대로 남는 바깥 틀에 연결했다. 처음에는 본문에 연결했다가 두 번째로 열 때 연결이 사라지는 것을 발견해 고쳤다.
  - `_show()` / `focus()` / `focusNearby()` / `focusCurated()` / `showPoint()`: 지도가 화면 밖이면 지도로 스크롤하고, 핀으로 옮겨 팝업을 연다. 팝업이 지도 위쪽을 넘으면 애니메이션 없이 바로 내린다.
  - 핀을 눌렀을 때 곧바로 스크롤하던 동작을 없앴다. 이제 팝업만 열고, 스크롤은 팝업을 눌렀을 때 한다.
- 화면별 연결

  | 화면 | 목록 → 지도 | 지도 → 목록 |
  |---|---|---|
  | 일정 만들기 | 일정 항목을 누르면 그날로 지도를 바꾸고 팝업을 연다 | 해당 일자 탭으로 바꾸고 항목으로 스크롤 |
  | 주변 맛집 | 카드 아무 곳이나 누르거나 기존 "지도에서 보기" 버튼 | 카드로 스크롤 |
  | 트렌드 코스 | 일정 줄, 가게 카드, 명소 카드. 휴대폰에서는 지도 탭으로 바꾼다. 일정에 없는 가게(대안)는 임시 핀으로 보여 준다 | 원래 탭으로 돌아가 스크롤 |
  | 동행 페이지 | 기존 카드 클릭에 지도 스크롤 추가, 근처 장소 줄, 미쉐린 목록 | 스팟 카드, 근처 장소 줄, 미쉐린 항목으로 스크롤 |

- 버튼·링크·입력 칸을 누르면 원래 동작만 한다.
- 팝업 설명 데이터
  - 일정 만들기: 장소 설명(`place.description`)
  - 트렌드: 일정 메모(`stop.note`)
  - 맛집 트렌드 픽: 소개 이유(`trend_reason`)

## 검증

- PASS `PYTHONUTF8=1 uv run pytest -q`: 943 passed. 트렌드 지도 테스트에 두 가지 확인을 추가했다.
  - 모든 핀에 팝업 설명이 있다.
  - 가게·명소를 가리키는 핀마다 되돌아갈 카드(`data-trend-ref`)가 있다.
- PASS `CWP_TEST_STORAGE=durable-object` API 263 passed. ruff 통과, `.github/quality/gate.py` 4/4.
- PASS 로컬 서버(8093)에서 클릭해 확인
  - 트렌드: 일정 줄 → 해당 팝업, 팝업 버튼 → 그 줄로 스크롤. 다른 날짜 줄은 지도 날짜도 바꿨다. 대안 가게(카우키)는 임시 핀으로 열렸고, 팝업을 누르면 카드로 돌아왔다. 핀을 누르면 팝업만 열리고 스크롤하지 않았다.
  - 일정 만들기(홍콩 추천 일정): 항목 → 팝업, 팝업 → 항목. 2일차 항목은 지도 날짜가 1(2일차)로 바뀌었다.
  - 주변 맛집(홍콩 트렌드 픽): 카드 → 팝업, 핀 팝업 → 카드.
  - 동행 페이지(로컬 DB에 테스트 여행을 만들어 확인): 스팟 카드 ↔ 핀, 미쉐린 항목 ↔ 핀. 근처 장소 줄은 위치 권한이 필요해 직접 누르지 못했다. 같은 `focusNearby` 를 쓰는 맛집 화면으로 대신 확인했다.
- 앱 안의 브라우저 창이 숨겨져 있어 애니메이션 프레임이 돌지 않았다. 그래서 화면 캡처는 헤드리스 Edge 원격 제어로 했다.
  - 휴대폰 폭에서 일정 줄을 누르면 지도 탭이 열리고 팝업이 지도 안에 모두 보였다(위 24px 여백).
  - 팝업을 누르면 그 줄이 화면 가운데에 강조됐다.
  - 데스크톱 맛집 화면에서도 확인했다.
