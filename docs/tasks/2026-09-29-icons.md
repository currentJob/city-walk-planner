# 아이콘 교체

사용자 요청: 배너·타이틀 등 아이콘이 어울리는 곳에 아이콘을 만들어 넣고 교체한다.

## 변경

- 로고: `c.` 글자 대신 경로 점선 + 핀 모양 SVG(`brand-mark`). 파비콘(`assets/favicon.svg`)도 같은 그림.
- `web/js/icons.js`: 24×24 선 아이콘 모음과 `icon(name, cls)`. 색은 글자색(`currentColor`)을 따른다. 운영체제마다 모양이 다른 이모지를 이 아이콘으로 바꿨다.
  - 트렌드 코스: 🕒 💳 📍 🎟 🛏. 숙소 문구의 🛏 는 데이터 문자열에서 빼고 화면에서 아이콘으로 붙인다.
  - 동행 일정: 🕐 🗑 📍 ⚠ ⏱, 날씨·환율 칩(맑음·구름·비·눈·뇌우 등), 지도 팝업.
- 섹션 제목 아이콘(`title-icon`): 도시 탐색, 일정 만들기, 주변 맛집, 내 여행, 트렌드 4개 섹션, 동행 페이지의 참여·점검·팁.
- `◎ 내 위치` 버튼은 위치 아이콘으로 바꿨다. "동행과 함께" 링크에 사람 아이콘을 넣었다. 데스크톱 상단 메뉴에도 아이콘을 보인다(이전에는 모바일에서만 보였다).
- 별점 ★ 과 화살표 ↗ → 는 글자 기호로 두었다.
